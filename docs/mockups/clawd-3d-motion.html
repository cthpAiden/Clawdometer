Clawd 3D — motion set

Model is T5: 64 slices × 1.3px, 51% depth ratio. Only the animation changes between cards.

Depth is visible only while rotateY or rotateX is non-zero. rotateZ, translate, scale and squash are in-plane — the slices stay stacked and the model reads as flat. That is exactly why the current 2D set shows none of the volume. N0 is that failure, kept as a control: same 64 slices, and it still looks like a sticker.

Second rule: parallax is a contrast effect. A fast turn out of stillness (N4, N5, N8) reads as more solid than a continuous sweep, even though the sweep covers more degrees.
