Clawd — 3D & animation concepts

Every sprite here is generated from the locked geometry (viewBox 0 0 100 70, body #e17956, arm reach 17u, eyes #111). Nothing is redrawn by eye. Depth is added behind or on top of that silhouette.

Left render = enlarged to judge the idea. Right render = the real HUD footprint (24.6 × 17.3 px). A concept that only works enlarged is not a concept — it is a poster.

A · Depth — extrusion behind the locked outline

Front-on silhouette untouched. A darker copy of the exact same rects is offset behind the sprite, so Clawd reads as a solid block instead of a decal.

B · Light & material — shading inside the outline

A unified light source across the whole sprite (gradientUnits="userSpaceOnUse"), so arms, body and legs are lit as one object rather than seven independent rectangles.

C · Motion — transform/opacity only

All of these are pure transform/opacity — required, since the transparent WebView2 window never repaints a moving background. At rest each returns to the exact locked pose.

D · True volume — real rotation

The sprite is stacked N times along Z in CSS 3D, so the object is a genuine extrusion of the locked silhouette. Dead-on it is pixel-identical to the shipped sprite; rotated, it is real geometry — not a fake.
